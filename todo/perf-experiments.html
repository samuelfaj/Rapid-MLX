1. Workflow protocol — try / eval / keep / revert

One change per experiment. No bundling. No parallel branches.

Per-experiment steps

  1. pre — confirm previous experiment landed clean.
  2. branch — exp/<id>-<slug> from main.
  3. snapshot_before — agentic sweep → reports/exp/<id>/before/.
  4. change — single edit. Commit exp(<id>): <desc>.
  5. snapshot_after — agentic sweep → reports/exp/<id>/after/.
  6. compare — summarize.
  7. verdict — apply gates. Record in verdict.md.
  8. act — merge if keep / delete branch if revert.
  9. log — append to reports/exp/INDEX.md.

Keep gates (ALL must pass)

IDCriterion
G1 agentic-shortΔ ≥ +5% tok/s on M5
G2 agentic-longΔ ≥ 0% on M5 (no regression)
G3 M1/M3 regressionwithin ±2% on both
G4 driftmean abs ≤ 1e-3 if numerics touched
G5 acceptanceMTP + n-gram Δpp within ±1pp
G6 maintenance≤ 1 flag OR ≤ 50 LOC

Revert triggers (ANY → revert)

  • Any G1–G5 fails
  • G6 fails (too much maintenance)
  • Test suite regression
  • Crash on M1 / M3 / M5

2. Experiment queue

Phase 1 — config quick wins (hours each)

E1 — m5_hw_profile_entry

Change
Add M5 / M5 Pro / M5 Max / M5 Ultra to HARDWARE_PROFILES in vllm_mlx/optimizations.py.
Hypothesis
Unknown chip falls back to 200 GB/s default → suboptimal heuristics.
Effort
hours • low risk
Gain
0% direct; unlocks E7

E2 — mtp_depth_sweep

Change
Sweep --mtp-num-draft-tokens ∈ {2, 3, 4, 5}. Bake winner into alias preset.
Hypothesis
Default 3 may be sub-optimal for agentic-short (tool structure repeats).
Effort
hours • low risk
Gain
+5–15% agentic-short

E3 — kv_turboquant_default_on

Change
Enable --kv-cache-turboquant by default in agentic profiles (vllm_mlx/agents/profiles/*.yaml).
Hypothesis
Decode is BW-bound; turboquant halves KV bytes; already shipped, just opt-in.
Effort
hours • low risk
Gain
+10–25% agentic-long decode

E4 — prefix_cache_size_tune

Change
Raise --prefix-cache-size default per agentic profile. Measure hit rate.
Hypothesis
Agentic sessions repeat tool scaffolding → fewer prefills if cache fits.
Effort
hours • low risk
Gain
+10–30% TTFT on repeat turns

E5 — chunked_prefill_default_on

Change
Default --chunked-prefill-tokens 8192 for agentic profiles when ctx > 16k.
Hypothesis
Prefill dominates long-turn TTFT; chunking lets next-turn gen start sooner.
Effort
hours • low risk
Gain
+5–15% mixed throughput

E6 — power_mode_doc

Change
Docs only: recommend sudo pmset -a powermode 2 + Game Mode for sustained bench.
Hypothesis
Thermal/power throttle widens bench noise band.
Effort
hours • no risk
Gain
Bench stability +5%; user gain marginal

Phase 2 — small code (days each)

E7 — auto_kv_bits_by_hw

Change
Auto-pick KV bits per HW: M1/M2 → fp16, M3+ → 8-bit, M5 → 6-bit. Single function in scheduler.py.
Hypothesis
Low-BW chips waste cycles on dequant; high-BW chips absorb 6-bit.
Effort
1 day • low–med
Gain
+5–15% M5, 0% M1

E8 — ngram_K_per_workload

Change
Per-profile override of --ngram-max-k (codex higher K, generic current).
Hypothesis
Agent traces have profile-specific repetition rates.
Effort
1 day • low risk
Gain
+3–10% agentic

E9 — nax_runtime_detect

Hypothesis
Precondition for later Metal4 kernel work; observability gain now.

1 day • low risk
Gain
0% direct; foundation for E16
